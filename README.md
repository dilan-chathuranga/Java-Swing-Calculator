# Java Swing Calculator 🧮

A simple and modern GUI Calculator developed using **Java Swing**.

## 📸 About the Project

This project is a desktop calculator application built using Java. It provides a user-friendly graphical interface with a dark theme and orange operator buttons.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Modulus (%)
- Decimal point support
- Clear All (AC)
- Backspace (←)
- Operator precedence
- Modern dark-themed GUI

## 🛠️ Technologies Used

- Java
- Java Swing
- AWT (Abstract Window Toolkit)
- JFrame
- JPanel
- JButton
- JTextField
- GridLayout

## 🚀 Getting Started

1. Download or clone this repository.
2. Open the project using a Java-supported IDE.
3. Run `my_calculator.java`.
4. Start calculating!
